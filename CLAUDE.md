# Loop Tuner

Reader: an agent working in this repository.

- Before changing anything, read [design/output/README.md](design/output/README.md): what was decided, and the status. The person's own words are in [design/input](design/input/README.md).
- When the person gives new design direction, save it verbatim as a new dated file in `design/input/`, then update `design/output/` and its decision log. The person does not want to explain things twice.
- Build with `node build.mjs`; test with `npm test`. No dependencies.
- To tune a loop for the person, follow [AGENTS.md](AGENTS.md).
