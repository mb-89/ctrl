# The library's buttons stacked (2026-10-25)

> Okay, maybe one more small thing that you can add to some other work package. And that is, in the library, the load, input, and plant buttons are currently horizontally next to each other. That takes up a lot of space and makes the text span over more lines. That's not necessary. Put them below each other, and then for the same width of the panel, you can make the text take more space.
