# A warning when the page runs in a limited environment (2026-10-25)

> So I guess one thing, but that's a small thing, really one, this is not that important, is we're going to put that HTML into SharePoint, right? And SharePoint shows previews of HTMLs if you click on them. But I, as far as I understand, these previews, they don't download external libraries if they are included. And I suppose that in this preview view, the system here will not properly work. You can usually detect this, that you're in this preview sandbox, by the fact that you can't download external libraries from a CDN, and by the fact that you don't have like local storage. So I feel like if you detect that you're running in a sandbox, there should be a warning label that's really impossible to miss right below the header that says we are running in a sandbox. For optimal performance, please download and run directly in the browser or something like this. Or maybe not running in a sandbox, running in a limited environment or something like this.
